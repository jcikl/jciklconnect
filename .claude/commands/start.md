# start

启动项目目标的自动推进流程。

## 执行协议

严格遵守以下文件：

1. `CLAUDE.md`
2. `AGENT-EXECUTION.md`
3. `TODO.md`
4. 相关代码与 `firestore.rules`
5. `SCHEMA.md`
6. `SCHEMA-PERMISSIONS.md`

执行要求：

- 读取 `TODO.md` 的当前目标、进行中任务和完成标准。
- 选择最高优先级且已批准的未完成任务。
- 先扫描现状，再执行最小必要修改。
- 每完成一个独立任务，运行适用的验证并更新 `TODO.md`。
- 当前任务完成后，自动继续下一个符合条件的任务，不等待用户重复输入“继续”。
- 范围外问题只登记到 `TODO.md`，不得自动扩大范围。
- 删除、数据迁移、权限扩大、架构变化、公共 API 变化或无法确定用户意图时暂停并说明原因。
- 没有可执行任务、目标已完成或验证无法安全修复时停止并报告。

## 输出要求

开始时简要报告当前目标和选中的任务；执行过程中报告关键阻塞；结束时报告已完成任务、验证结果、剩余任务和需要确认的事项。

`/start` 只能驱动当前已启动的 agent 会话；它不会在 Claude Code 关闭后自行唤醒新会话。
